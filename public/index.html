Prison Yard Chess

What This Prototype Is Trying to Prove

01

The public game is never the real game

Every activity still has a visible layer like chess, cards, handball, chow, work detail, or commissary, but the meaningful decision is always social and positional.

02

Space should create tension on its own

The prototype proves that cells, the yard, chow hall, showers, and the walk can all feel politically different before a single line of dialog explains why.

03

Consequences should stack across the slice

Heat, leverage, safety, respect, energy, money, favors, and contraband all move together so one smart compromise can still corner you later.

04

The next version can grow wider and meaner

If this lands, the format can expand into longer schedules, more inmates, faction pressure, guard systems, contraband routes, and a bigger prison social map.
