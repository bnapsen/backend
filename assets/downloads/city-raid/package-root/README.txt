City Raid

Quick start
1. Extract the full zip before trying to run the game.
2. Double-click INSTALL-CITY-RAID.bat if you want a simple install with shortcuts.
3. Run HOST-CITY-RAID-MULTIPLAYER.bat to open a co-op room and publish it to bnapsen.com.
4. Run JOIN-CITY-RAID-MULTIPLAYER.bat to paste a room code and jump into a live raid.
5. You can still run PLAY-CITY-RAID.bat or FIRSTPERSON.exe directly for solo play.

Notes
- The installer uses your current Windows account and does not require Unreal Engine.
- The default install location is under your Local AppData Programs folder.
- The installer creates Start Menu shortcuts for play, host, join, and the website.
- Hosting uses port 7777 by default. If friends cannot join, forward UDP 7777 on your router.
- Live room board and room links: https://bnapsen.com/city-raid.html
