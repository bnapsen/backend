Host a raid

Download the build, extract it, and run HOST-CITY-RAID-MULTIPLAYER.bat. The helper registers your room on this page, prints a room code, keeps it alive while the game is open, and gives you a share link for friends.

  1. Download and extract the Windows zip.
  2. Run HOST-CITY-RAID-MULTIPLAYER.bat.
  3. Share the room code or share link it gives you.

Default host flow uses port 7777. If your router blocks it, the helper tells you what to forward.

What is in the zip

The package includes the full City Raid Windows build, Unreal prerequisites, a quick-play launcher, the install assistant, and multiplayer host and join helpers.

Host flow

Run HOST-CITY-RAID-MULTIPLAYER.bat to launch a listen-server, publish a room code, and keep the room live on this website while you play.

Join flow

Run JOIN-CITY-RAID-MULTIPLAYER.bat and paste a room code, or copy a launch line from the live room board above.

  1. Download the Windows zip package.
  2. Extract the archive fully before trying to launch the game.
  3. Run INSTALL-CITY-RAID.bat for the guided install assistant, or jump straight into HOST-CITY-RAID-MULTIPLAYER.bat or JOIN-CITY-RAID-MULTIPLAYER.bat.

Portable build size: about 407 MB zipped and about 508 MB extracted.
