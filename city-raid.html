Host a raid

Download the game with the assistant, extract it fully, then unzip the co-op helper pack into the same folder as FIRSTPERSON.exe. Run HOST-CITY-RAID-MULTIPLAYER.bat and it will register your room on this page while the game is open.

  1. Run City-Raid-Download-Assistant.cmd and extract the rebuilt zip.
  2. Unzip City-Raid-Coop-Helpers.zip into the extracted game folder.
  3. Run HOST-CITY-RAID-MULTIPLAYER.bat and share the room code it gives you.

Default host flow uses port 7777. If your router blocks it, forward UDP 7777 and allow the game through Windows Firewall.

Download notes

How to get the game and co-op tools in the right places

Game download

The game itself is served as five split download parts plus a Windows assistant that rebuilds the full zip for you.

Co-op helper pack

The host and join scripts are in a separate helper zip so the website can evolve the multiplayer flow without repackaging the whole game build every time.

What goes where

Extract the game first, then drop the helper pack contents into that same extracted folder so the batch files can find FIRSTPERSON.exe.

  1. Download City-Raid-Download-Assistant.cmd and let it rebuild the full Windows zip.
  2. Extract the rebuilt archive fully before trying to launch the game.
  3. Download City-Raid-Coop-Helpers.zip and unzip it into the extracted game folder.
  4. Run HOST-CITY-RAID-MULTIPLAYER.bat or JOIN-CITY-RAID-MULTIPLAYER.bat.

Reconstructed game zip size: about 402 MB. Extracted size is a little over 1 GB.

Co-op helper pack size: about 6 KB. It includes the host, join, install, and quick-play helpers plus a short README.
