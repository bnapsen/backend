City Raid

City Raid is the latest Unreal prototype in the Nova lineup: a stripped-down urban survival run with wave pressure, long-range beacon markers, and a custom hero-style pass before you deploy into the block.

Why it stands out

A harder-edged Unreal experiment for the arcade floor

Wave pressure

The current build already frames the action around active waves, enemy counts, and quick-survival pacing instead of a slow sandbox crawl.

Beacon-driven navigation

Long-range objective markers give the prototype a clean arcade read, pulling you across the city instead of trapping you in one corner.

Hero style pass

The project includes a pre-deploy character styling pass, giving City Raid a stronger identity than a default shooter greybox.

Built fast, already distinct

This is exactly the kind of Unreal side project that belongs next to Dragonfall: rough in spots, but already carrying its own visual lane and combat mood.
